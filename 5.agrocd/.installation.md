# Argo CD Installation and Setup (Kind / Kubernetes)

## Prerequisites

- Kubernetes cluster running
- kubectl configured
- Internet connection

---

# Step 1: Create Argo CD Namespace

```bash
kubectl create namespace argocd
```

---

# Step 2: Install Argo CD

```bash
kubectl apply -n argocd -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```

---

# Step 3: Verify Installation

```bash
kubectl get pods -n argocd
```

Wait until all pods are in the **Running** state.

---

# Step 4: Check Services

```bash
kubectl get svc -n argocd
```

---

# Step 5: Port Forward Argo CD Server

```bash
kubectl port-forward svc/argocd-server -n argocd 8080:443
```

---

# Step 6: Access Argo CD

Open your browser:

```
https://localhost:8080
```

Accept the browser security warning (self-signed certificate).

---

# Step 7: Get Initial Admin Password

```bash
kubectl -n argocd get secret argocd-initial-admin-secret \
-o jsonpath="{.data.password}" | base64 -d
```

---

# Step 8: Login

**Username**

```
admin
```

**Password**

```
<Output from Step 7>
```

---

# Step 9: Change the Admin Password (Recommended)

```bash
argocd account update-password
```

---

# Step 10: Install Argo CD CLI (Ubuntu / RHEL)

```bash
curl -sSL -o argocd \
https://github.com/argoproj/argo-cd/releases/latest/download/argocd-linux-amd64
```

```bash
chmod +x argocd
```

```bash
sudo mv argocd /usr/local/bin/
```

Verify:

```bash
argocd version
```

---

# Step 11: Login Using CLI

```bash
argocd login localhost:8080 --username admin
```

Enter the password obtained in **Step 7**.

---

# Verify Installation

Check Namespace

```bash
kubectl get ns
```

Check Pods

```bash
kubectl get pods -n argocd
```

Check Services

```bash
kubectl get svc -n argocd
```

Check Deployments

```bash
kubectl get deploy -n argocd
```

---

# Useful Commands

List Applications

```bash
argocd app list
```

List Projects

```bash
argocd proj list
```

View Cluster

```bash
argocd cluster list
```

Logout

```bash
argocd logout localhost:8080
```

Delete Argo CD

```bash
kubectl delete namespace argocd
```
