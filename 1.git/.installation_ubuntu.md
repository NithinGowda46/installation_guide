# Git Installation and GitHub SSH Authentication on Ubuntu

## Step 1: Update the System

    sudo apt update
    sudo apt upgrade -y

## Step 2: Install Git

    sudo apt install git -y

## Step 3: Verify Git Installation

    git --version

## Step 4: Configure Git Username

    git config --global user.name "Nithin Gowda"

## Step 5: Configure Git Email

    git config --global user.email "nithingowdai46@gmail.com"

## Step 6: Verify Git Configuration

    git config --global --list

# GitHub Authentication Using SSH

GitHub does not require a separate "git login" command when using SSH.

SSH keys are used for authentication.

## Step 7: Generate SSH Key

    ssh-keygen -t ed25519 -C "nithingowdai46@gmail.com"

Press Enter to use the default location.

The keys will be created at:

    ~/.ssh/id_ed25519
    ~/.ssh/id_ed25519.pub

## Step 8: Start SSH Agent

    eval "$(ssh-agent -s)"

## Step 9: Add SSH Key to SSH Agent

    ssh-add ~/.ssh/id_ed25519

## Step 10: Display the Public Key

    cat ~/.ssh/id_ed25519.pub

Copy the complete output.

Never share:

    ~/.ssh/id_ed25519

Only the public key:

    ~/.ssh/id_ed25519.pub

should be added to GitHub.

## Step 11: Add SSH Key to GitHub

Go to:

    GitHub
    → Settings
    → SSH and GPG keys
    → New SSH key

Title:

    Ubuntu-GitHub

Paste the output of:

    cat ~/.ssh/id_ed25519.pub

Then click:

    Add SSH key

## Step 12: Test GitHub SSH Authentication

    ssh -T git@github.com

If GitHub asks:

    Are you sure you want to continue connecting?

Enter:

    yes

    cd Project1-notesapp-devops
